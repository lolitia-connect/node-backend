- 官方同步使用 `<last-official-tag>-to-<new-official-tag>.md`。
- 同步后定制使用 `<last-official-tag>-local-<YYYY-MM-DD>.md`，配套 `.files.md`。
- 差异记录、prompt 和索引只保存为 Markdown；写具体行为、兼容边界、关键入口和实际验证，不只列提交标题。
